
# LPC2129 Embedded C Programs

Practice programs for the LPC2129 ARM7 microcontroller.

**Toolchain:** Keil µVision / Flash Magic
**Board:** LPC2129

## Programs

| File | Description |
|------|-------------|
| 01_Switch_LED_Pattern.c | LED pattern controlled by switch input |
| 02_Switch_press_count_binary_LED_display.c | Displays switch press count in binary on LEDs |
| 03_Up_Down_counter.c | Up/down counter |
| 04_Switch_press_count_500ms.c | Counts switch presses with 500ms debounce/delay |
| 05_One_Second_Up_and_Down_Counter.c | Up/down counter with 1-second timer |
| 06_Even_Odd_Number_LED_Display.c | Displays even/odd number status on LEDs |
